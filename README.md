# Pilates Prep 器械皮拉提斯備課系統

Pilates Prep 是為器械皮拉提斯老師設計的離線優先 PWA，專注在「備課、背課、帶課」三個流程。資料只存於目前裝置的 IndexedDB，不需要帳號或後端。

## 使用方式

線上版本：<https://mike41907.github.io/pilates-teacher-prep/>

第一次開啟後，可由瀏覽器選單安裝到手機、iPad 或電腦主畫面。安裝並成功載入一次後，核心功能可離線使用。

## v0.5.0 功能

- 內建 135 個器械皮拉提斯動作：Reformer 60、Cadillac 30、Chair 30、Barrel 15
- 每筆內建動作都有中英文名稱、器械、程度、部位、姿勢、時間、可編輯 Cue 與原始資料來源
- 多個常用動作／系列提供 Pilates Anytime 原始線上示範入口；不複製第三方影片檔
- 舊裝置會自動且只執行一次動作目錄升級，不覆蓋老師修改過的名稱、Cue、收藏或課表
- 市場資料的彈簧預設保留為「依器械／學員調整」，避免把單一品牌顏色誤當通用標準
- 動作編輯頁可自行修改資料來源與線上示範 HTTPS 網址

- 動作可分別保存「動作總覽、退階、正常、變化」四段示範短影片
- 影片從手機相簿或裝置選取後存進 IndexedDB，可完全離線播放
- 動作庫與備課挑選畫面提供「快速回想」，不需要進入完整影片平台
- 單段影片上限 25 MB，介面顯示檔名、大小與離線狀態
- 完整備份可攜帶影片；另提供較小的純資料備份，匯入時驗證影片內容

- 每個課程動作固定包含「退階 → 正常 → 變化」三階教學流程
- 三階可分別編輯版本名稱、做法、專屬 Cue、次數與時間，總時間自動加總
- 可把課內調整儲存為該動作的預設三階流程，下次加入時直接套用
- 完整腳本、Cue 背課與現場帶課畫面同步顯示三階流程
- 舊課表與 v1／v2 備份會自動建立三階流程，不會遺失原有 Cue 或課程

- 動作 CRUD、即時搜尋、多條件篩選、收藏與 7／30 天使用統計
- 課程建立、Section、觸控長按拖曳、跨 Section 排序、時間與結構分析
- 依器械、難度、部位、時間與限制條件推薦替代動作
- 課內 Cue 快照、完整腳本、三種背課模式及只練不熟動作
- 帶課大字模式、上一個／下一個、鍵盤控制與 Wake Lock fallback
- 整堂課、目前動作、Section 計時；支援正數、倒數、暫停、補時及提示音／震動
- 帶課中斷後復原進度，並把實際動作時間用於下次備課預估
- 模板、課程複製、相似度、使用紀錄
- 完整 JSON 備份（可含影片）、逐欄驗證、舊版遷移、合併／覆蓋及匯入前安全備份
- 可持久化儲存狀態、PWA 新版提示與離線快取

示範 Cue 僅供測試與自訂，不代表醫療建議或唯一教學標準。

## 本機開發

```bash
pnpm install
pnpm dev
```

## 驗證

```bash
pnpm run typecheck
pnpm run test
pnpm run build
pnpm run test:e2e
```

端對端測試涵蓋 390×844 手機、iPad 直向與 iPad 橫向。GitHub Pages 部署流程會先執行型別檢查、單元測試與正式建置。

## 資料與隱私

- 不使用雲端 API、CDN、分析追蹤或遙測。
- 清除網站資料可能刪除本機課表與影片；請定期在「設定 → 備份與還原」匯出「完整備份（含影片）」。
- 匯入會先驗證格式，並自動下載目前資料的安全備份，不會直接靜默覆蓋。
