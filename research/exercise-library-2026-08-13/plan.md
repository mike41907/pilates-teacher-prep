# 器械皮拉提斯動作庫研究計畫

日期：2026-08-13

## 決策問題

如何在不宣稱單一流派為唯一標準、也不侵犯教學影片著作權的前提下，為 Pilates Prep 建立至少 100 個可實際搜尋與備課的器械動作？

## 可驗證假設

1. Reformer、Cadillac／Trapeze Table、Wunda Chair、Ladder Barrel 四類公開課綱足以交叉核對 100 個以上的常見動作名稱。
2. 不同品牌及流派的彈簧配置不可視為通用標準，因此內建資料應保留教師調整空間。
3. 公開教學頁面可作為外部參考連結，但影片檔不應複製進公開 GitHub 專案。
4. 既有使用者升級時，新增內建動作不可覆蓋自訂 Cue、課程或已刪除的動作。

## 範圍

- 納入：Reformer、Cadillac、Chair、Barrel。
- 排除：純 Mat、醫療診斷、復健處方、AI 風險判斷。
- 目標：至少 120 筆穩定 ID 的內建動作，附器械、程度、部位、姿勢、時間、原創提示與來源。
- 影片：只保存 HTTPS 外部連結；老師自己的短片仍使用本機 IndexedDB。

## 來源策略

- 主要課綱：Contrology Cohort、Pilatesology、Balanced Body。
- 補充動作表：Birmingham Pilates Studios、Vintage Pilates。
- 示範頁：Pilates Anytime 的器械教學與系列影片。

## 風險控制

- 同名異式：保留英文原名、器械與系列前綴。
- 流派差異：Cue 明示為可編輯示範內容，不寫成唯一標準。
- 彈簧差異：預設顯示「依器械／學員調整」。
- 影片權利：只連結原始頁，不下載、不鏡像、不嵌入 GitHub。
- 升級資料：以目錄版本一次性合併，不覆寫同 ID 資料。

## 停止條件

- 四類器械合計至少 120 筆，無重複 ID。
- 每一類至少有一個主要來源與一個補充來源。
- 單元測試、正式建置、手機及 iPad 核心流程通過。
